# Neon Bounce

A fast-paced, neon-styled 2D rolling ball platformer built with vanilla JavaScript and HTML5 Canvas. Collect rings, avoid hazards, solve light platforming puzzles, and reach the exit portal across 5 challenging levels.

---

## 🎮 How to Play

Open `index.html` in any modern web browser or serve it with a local static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```

### Controls

| Action | Desktop (Keyboard) | Mobile / Touch |
| :--- | :--- | :--- |
| **Move Left** | `A` or `Left Arrow` | Left Arrow Button |
| **Move Right** | `D` or `Right Arrow` | Right Arrow Button |
| **Jump** | `W`, `Up Arrow`, or `Space` | Jump Button (▲) |

---

## ✨ Features

- **5 Handcrafted Levels:** Progressive difficulty featuring spikes, gates, moving platforms, and slippery ice surfaces.
- **Physics Engine:** Custom 2D ball physics with rolling rotation, momentum, variable jump heights, and collision response.
- **Visuals & Effects:** Neon particle system, dynamic camera tracking, and glowing visual cues.
- **Responsive & Accessible:** Full support for desktop keyboard navigation and mobile touch controls.
- **Zero Dependencies:** Pure HTML5 Canvas, Vanilla CSS, and JavaScript with no external libraries.
